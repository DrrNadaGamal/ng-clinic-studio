# تشغيل NG Clinic Studio

هذا مشروع عرض أعمال ببيانات وهمية فقط، وليس نظاماً طبياً جاهزاً للاستخدام الفعلي.
تم التطوير بمساعدة AI وبتوجيه ندى جمال. لا تضعيه على موقع العيادة الحقيقي.

1. افتحي موقع WordPress تجريبي في LocalWP وخذي نسخة احتياطية.
2. من إضافات > أضف جديد > رفع إضافة، ارفعي ملف ng-clinic-studio-1.0.0.zip.
3. فعّلي الإضافة. ستنشئ ١٢ سجلاً و١٢ موعداً وهمياً تلقائياً.
4. اضبطي المنطقة الزمنية في إعدادات WordPress، مثلاً Africa/Cairo.
5. افتحي Clinic Studio من لوحة التحكم ثم Open Clinic Studio.
6. زر Booking preview يفتح صفحة الحجز التجريبية. يمكن أيضاً وضع
   `[ng_clinic_booking]` في عنصر Shortcode في WordPress أو Elementor.
7. بدّلي اللغة من زر العربية. الواجهة تدعم RTL.

جرّبي حجز موعد باسم وهمي، ثم ارجعي لصفحة المواعيد واختاري تاريخ الحجز.
يمكن تسجيل الحضور، إكمال الزيارة أو إلغاء الموعد حسب حالته.
الملاحظات متاحة للمدير والطبيب فقط، وليست لموظف الاستقبال.

لا يتم إرسال بريد أو واتساب، ولا توجد مدفوعات. الأسعار تجريبية فقط.
الملاحظات غير مشفرة. لا تدخلي أي بيانات مرضى حقيقية.
تعطيل الإضافة يحتفظ بالبيانات؛ حذفها من WordPress يحذف جداولها وبياناتها.
المشروع لا يزال يحتاج مراجعة أمن وخصوصية واختبار MySQL وElementor الفعلي
قبل أي قرار بتوسيعه. هذه النسخة Demo جاهزة للتجربة والعرض، وليست Production.
